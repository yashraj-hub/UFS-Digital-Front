# UFS Digital React Skeleton

Simple six-page React website for **UFS Digital** with:

- Shared global theme (`headings`, `paragraphs`, `navbar`, `footer`)
- Reusable layout (`Navbar + page content + Footer`)
- React Router setup for 6 pages

## Pages

- Home
- About
- Services
- Projects
- Blog
- Contact

## Run locally

```bash
npm install
npm run dev
```
